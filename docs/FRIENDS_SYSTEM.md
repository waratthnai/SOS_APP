# ระบบเพื่อน (Friends System) - SOS Off-Grid

## สิ่งที่เพิ่มเข้ามาใหม่

### 1. โครงสร้างข้อมูล (Data Models)
- **Friend Model** (`lib/core/friend_models.dart`)
  - ข้อมูลเพื่อน: ID, ชื่อ, User ID, สถานะออนไลน์, ข้อความสุดท้าย
  - ข้อมูลโปรไฟล์ผู้ใช้: User ID, ชื่อ, อีเมล, รูปโปรไฟล์, คำอธิบาย
  - คำขอเป็นเพื่อน: ผู้ส่ง, ผู้รับ, สถานะ, ข้อความแนะนำตัว

- **Friend Chat Message Model** (`lib/core/chat_models.dart`)
  - ข้อความแชทเพื่อน: ผู้ส่ง/รับ User ID, ประเภท, เนื้อหา, สถานะการอ่าน

### 2. การจัดการข้อมูลท้องถิ่น (Local Storage)
- **Friend Database** (`lib/core/friend_db.dart`)
  - บันทึก/ดึงข้อมูลเพื่อน, โปรไฟล์ผู้ใช้, คำขอเป็นเพื่อน
  - จัดการข้อความแชทเพื่อนในฐานข้อมูลท้องถิ่น
  - ทำงานแบบออฟไลน์ได้

### 3. บริการระบบเพื่อน (Friend Service)
- **Friend Service** (`lib/core/friend_service.dart`)
  - จัดการสถานะเพื่อน, ค้นหาผู้ใช้, ส่งคำขอเป็นเพื่อน
  - ยอมรับ/ปฏิเสธคำขอ, อัพเดทสถานะออนไลน์
  - Sync ข้อมูลระหว่าง Firebase และท้องถิ่น

### 4. การขยาย Firebase Service
- **เพิ่มฟังก์ชันใน Firebase Service** (`lib/cloud/firebase_service.dart`)
  - สร้าง User ID ที่ไม่ซ้ำ
  - ค้นหาผู้ใช้จากชื่อ
  - จัดการคำขอเป็นเพื่อน
  - บันทึก/ดึงข้อความแชทเพื่อน

### 5. การขยาย App State
- **เพิ่มการจัดการแชทเพื่อนใน App State** (`lib/core/app_state.dart`)
  - ส่งข้อความให้เพื่อน (ออนไลน์/ออฟไลน์)
  - รับข้อความจากเพื่อนผ่าน transport protocols
  - โหลดและจัดการประวัติแชทเพื่อน

### 6. หน้าจอใหม่ (UI Screens)

#### 6.1 หน้าจอเพื่อน (`lib/ui/friends_screen.dart`)
- แสดงรายชื่อเพื่อนทั้งหมด
- แสดงเพื่อนที่ออนไลน์
- บอกจำนวนข้อความที่ยังไม่อ่าน
- ลิงก์ไปยังหน้าแชท, เพิ่มเพื่อน, คำขอเป็นเพื่อน

#### 6.2 หน้าจอเพิ่มเพื่อน (`lib/ui/add_friend_screen.dart`)
- ค้นหาผู้ใช้ด้วยชื่อ
- แสดงโปรไฟล์ของตัวเอง (User ID)
- ส่งคำขอเป็นเพื่อนพร้อมข้อความแนะนำตัว

#### 6.3 หน้าจอคำขอเป็นเพื่อน (`lib/ui/friend_requests_screen.dart`)
- แสดงคำขอเป็นเพื่อนที่ได้รับ
- ยอมรับ/ปฏิเสธคำขอ
- แสดงข้อความแนะนำตัวจากผู้ส่งคำขอ

#### 6.4 หน้าจอแชทเพื่อน (`lib/ui/friend_chat_screen.dart`)
- แชทกับเพื่อนแบบ real-time
- แสดงสถานะออนไลน์/ออฟไลน์
- ข้อความแสดงสถานะการส่ง/อ่าน
- ล้างประวัติแชท, ดูข้อมูลเพื่อน

#### 6.5 หน้าจอโปรไฟล์ (`lib/ui/profile_screen.dart`)
- แก้ไขชื่อและคำอธิบายตัวเอง
- แสดง User ID สำหรับแชร์
- สถิติเพื่อน (จำนวนเพื่อน, ออนไลน์, ข้อความที่ยังไม่อ่าน)
- ข้อมูลบัญชี

### 7. การเพิ่มส่วนเพื่อนในหน้าหลัก
- **หน้าหลัก** (`lib/main.dart`)
  - เพิ่มการ์ดเพื่อนหลังจาก Emergency Contacts
  - แสดงเพื่อน 3 คนแรก, สถานะออนไลน์, จำนวนข้อความที่ยังไม่อ่าน
  - ปุ่มไปยังหน้าจัดการเพื่อน

- **หน้าตั้งค่า** 
  - เพิ่มการ์ดโปรไฟล์ผู้ใช้
  - แสดงข้อมูลโปรไฟล์พื้นฐาน
  - ปุ่มแก้ไขโปรไฟล์

## วิธีการทำงาน

### ระบบออนไลน์ (มีอินเทอร์เน็ต)
1. **เพิ่มเพื่อน**: ค้นหาด้วยชื่อ → ส่งคำขอ → ยอมรับ/ปฏิเสธ
2. **แชท**: ส่งข้อความผ่าน Firebase → บันทึกทั้งท้องถิ่นและ Firebase
3. **Sync**: ข้อมูลซิงค์ระหว่าง Firebase และเครื่องท้องถิ่น

### ระบบออฟไลน์ (ไม่มีอินเทอร์เน็ต)
1. **แชท**: ใช้เพื่อนที่เพิ่มไว้แล้ว → ส่งผ่าน nearby/BLE/WiFi Direct
2. **เก็บข้อมูล**: บันทึกข้อความในเครื่องท้องถิ่น
3. **Auto-sync**: เมื่อมีอินเทอร์เน็ตกลับมา จะซิงค์ข้อมูลอัตโนมัติ

### การส่งข้อความ
- **Online**: Firebase Real-time Database
- **Offline**: Nearby Connections / BLE / WiFi Direct
- **Format**: `FRIEND_MSG:fromUserId:message`

## การตั้งค่าเพิ่มเติม

### Dependencies ที่เพิ่ม
```yaml
shared_preferences: ^2.3.2  # สำหรับเก็บข้อมูลท้องถิ่น
```

### Firebase Collections ใหม่
1. **users** - ข้อมูลโปรไฟล์ผู้ใช้
2. **friend_requests** - คำขอเป็นเพื่อน  
3. **friend_chats** - ข้อความแชทเพื่อน
4. **users/{userId}/friends** - รายชื่อเพื่อนของแต่ละคน

## คุณสมบัติหลัก

✅ **เพิ่มเพื่อนผ่าน User ID**
✅ **แชทกับเพื่อนทั้งออนไลน์และออฟไลน์**
✅ **จัดเก็บข้อมูลท้องถิ่น (ทำงานโดยไม่ต้องมีอินเทอร์เน็ต)**
✅ **Auto-sync เมื่อมีอินเทอร์เน็ต**
✅ **แสดงสถานะออนไลน์/ออฟไลน์**
✅ **นับข้อความที่ยังไม่อ่าน**
✅ **ระบบคำขอเป็นเพื่อน**
✅ **โปรไฟล์ผู้ใช้ที่แก้ไขได้**

## การใช้งาน

1. **เพิ่มเพื่อน**: หน้าหลัก → ไปที่เพื่อน → เพิ่มเพื่อน → ค้นหาด้วยชื่อ
2. **ดูคำขอ**: หน้าเพื่อน → ไอคอนคำขอ (มี badge หากมีคำขอใหม่)
3. **แชท**: คลิกที่เพื่อนเพื่อเข้าสู่หน้าแชท
4. **แก้ไขโปรไฟล์**: หน้าตั้งค่า → แก้ไขโปรไฟล์

ระบบนี้ทำให้ผู้ใช้สามารถเพิ่มเพื่อนเมื่อมีอินเทอร์เน็ต และแชทกันได้ทั้งเมื่อมีและไม่มีอินเทอร์เน็ต โดยข้อมูลจะถูกซิงค์อัตโนมัติเมื่อกลับมาออนไลน์
