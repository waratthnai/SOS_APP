🎨 วิธีสร้างไอคอน SOS

  1. คลิกปุ่ม "Download Main Icon (1024x1024)" → บันทึกเป็น app_icon.png
  2. คลิกปุ่ม "Download Foreground (432x432)" → บันทึกเป็น app_icon_foreground.png
  3. วางไฟล์ทั้ง 2 ใน folder: assets/icon/
  4. รันคำสั่ง: flutter pub get
  5. รันคำสั่ง: flutter pub run flutter_launcher_icons
  6. Build ใหม่: flutter build apk --release
